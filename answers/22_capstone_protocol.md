# Lesson 22 answer key — Design a bounded independent research study

Attempt the assignments before reading. Different code is welcome; the evidence and reasoning must agree.

## A1

Accept a narrowly scoped claim with an observable target and a genuine baseline. Example: “On a predetermined four-issuer prospective panel, compare frozen text+market versus market-only preopen three-class response forecasts by equal-date NLL, using actual receipt/version logs and a frozen validation-selected procedure. Reject promotion if incremental evidence is unfavorable or coverage/timing fail the contract.” Name the independent evaluation dates/acquisition rule without falsely claiming existing inspected data are fresh. Cost/PnL is separate unless the protocol actually models execution.

## A2

The complete worked Project 8 packet is a structural reference. Your plan needs executable field definitions and interval rules, not a promise to clean data later. The fixture should catch future revisions, missing source clocks, unequal model populations and unavailable labels. Resource estimates distinguish acquisition/storage from inference/training. If data access is unavailable, a feasibility capstone with a tested schema and documented evidence gap is acceptable; it must not report fabricated empirical results.

## A3

Strong pre-mortem: engagement-conditioned sampling → compare prospectively fixed coverage, unresolved by archive alone; model-date contamination → use a frozen model prospectively; optimistic fills → validate against actual execution/queue data, unavailable in daily bars. Choose a next experiment that addresses one uncertainty and keep others explicit. Changing representation, population and costs at once makes attribution difficult.

Repair: if your abstract names architectures but no measurable outcome, rewrite it before any new training.
