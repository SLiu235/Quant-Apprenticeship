# Choose experiments by observations and resources

| Available observations | Laptop core | Single GPU extension | Larger compute extension | Claim ceiling without additional observations |
|---|---|---|---|---|
| Selected daily bars and archived public text | Audit clocks/selection, linear baselines, paired forecast tests | Frozen encoder/sequence-model comparisons | Controlled representation sweeps, cross-source replication | Selected-population response forecasts; no investor actions, causal exposure or verified fills |
| Timestamped quote/trade/order events | Parser/replay fixtures, event baselines, fill calibration | Richer event/sequence models | Multi-venue replay and stress scenarios | Order-flow and execution predictions under observed feed/queue scope; not automatically investor objectives |

## Practical upgrade rule

Write the uncertainty first: missing observations, weak representation, optimization variance, regime coverage, execution validity or runtime bottleneck. Estimate what the upgrade changes. Acquire data to observe a missing state; use compute to fit/test a specified model class faster or at larger scale. Neither automatically solves the other problem.

Before large training, run a tiny correctness fixture, a baseline and one end-to-end timing. Before paid acquisition, check actual fields, dates, receipt/version semantics, sampling, identifiers, licensing and the evaluation plan. A correct feasibility stop is a research deliverable.

## Specialist paths after graduation

- Predictive equity research: broaden the point-in-time universe, factor exposures and event study design; build a replicated cross-sectional study with delisting/corporate-action handling.
- Execution research: learn a specific venue's order/feed semantics, queue inference and transaction-cost measurement; validate replay against observed execution logs.
- Behavioral/causal research: study partial observability, identification and experimental/quasi-experimental design; define a measurable exposure intervention before a graph claim.
- Derivatives research: extend contract cashflows to stochastic pricing, volatility surfaces, Greeks and hedging error; daily equity forecasts are not sufficient preparation for specialist pricing.
- Research engineering: build durable data lineage, scalable feature computation and monitored paper operation with recovery tests; demonstrate correctness under failure before performance claims.
