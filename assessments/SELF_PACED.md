# Optional assessment and evidence review

All diagnostics, lesson self-scores and integrated worksheets are optional. Earlier course files contain mandatory-sounding pass rules; treat those as suggested self-review standards rather than automatic gates. The current apprenticeship policy takes precedence.

Mentor assessment happens only when you request assessment, submit work for review, ask whether you are ready to advance, have a major misconception blocking further progress, or reach a substantial milestone whose correctness must be verified before dependent work can be trusted. No quizzes are automatically administered after sections.

## How to use a worksheet

Attempt the numerical case, debugging investigation and decision memo when useful. Save your original answer before opening the linked hints and key. Mark each project criterion as evidenced, partial or unverified, with a link to the artifact. You can work independently and return for review when you choose.

## Optional rubric

| Dimension, in review order | Evidence to examine |
|---|---|
| Correctness | Independent arithmetic; conservation; stated behavior on boundaries |
| Research validity | Information timing; sampling; unseen evaluation; comparison population |
| Simplicity | Responsibilities and complexity justified by the problem |
| Maintainability | Clear interfaces and assumptions that another engineer can follow |
| Reliability | Invalid inputs, retries, partial results, interrupted work and recovery |
| Performance | Measured adequacy for the stated workload, not speculative optimization |
| Architecture | Data ownership, boundaries, observability and change isolation |
| Testing | Meaningful failure fixtures and invariants, beyond copying implementation |

Use 0 = no evidence, 1 = major unresolved errors, 2 = partial evidence, 3 = adequate independent evidence, 4 = evidence challenged by changed fixtures and alternatives. A sum is optional and is not a competency certification. Do not average away a leakage or accounting failure before building a dependent milestone on that result.

## Mentor review response

First identify what is correct, questionable and wrong, then the assumptions and next investigation. Guide diagnosis before providing a replacement implementation. Promotion to Builder, Researcher, Senior Researcher, Portfolio Engineer or System Owner/PM requires actual evidence and an explicit readiness discussion.
